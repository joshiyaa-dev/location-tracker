# location-tracker

Real-time GPS location tracker built with vanilla JavaScript and Geolocation API.

## Features
- Live coordinate tracking (latitude/longitude)
- Accuracy radius display (meters)
- Speed detection (m/s and km/h)
- Location history trail (latest 20 points)
- Shareable Google Maps links for current and historical points

## Usage
1. Open `index.html` in a browser.
2. Click **Start Tracking** and allow location permission.
3. Watch live updates and open Google Maps links as needed.
4. Click **Stop Tracking** to end tracking.
